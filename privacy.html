Политика конфиденциальности

Версия 1.0 от 10 июня 2026 г.

1. Общие положения

1.1. Настоящая Политика конфиденциальности описывает порядок сбора, обработки, хранения и защиты персональных данных пользователей сервиса BizPanel.

1.2. Оператором персональных данных является: (реквизиты ИП/ООО — заполнить после регистрации) (далее — «Оператор»).

1.3. Политика разработана в соответствии с Законом Республики Узбекистан «О персональных данных» (ЗРУ-547 от 02.07.2019).

1.4. Используя Сервис, Пользователь подтверждает, что ознакомился с настоящей Политикой и выражает согласие на обработку персональных данных в описанном объёме.

2. Собираемые персональные данные

2.1. Данные при регистрации:

  • адрес электронной почты (обязательно);
  • имя пользователя (по желанию);
  • пароль — хранится исключительно в виде необратимого криптографического хеша (bcrypt). Оператор не имеет доступа к паролю в открытом виде.

2.2. Данные при использовании Telegram-бота (@BizPanelXBot):

  • Telegram Chat ID (числовой идентификатор);
  • Telegram username (если установлен).

2.3. Данные, собираемые автоматически:

  • IP-адрес при входе в систему — хранится не более 90 дней;
  • User-Agent браузера;
  • аудит-лог действий в Сервисе.

2.4. Данные при оплате:

Реквизиты банковских карт Оператором не собираются и не хранятся. Платёжные данные передаются непосредственно платёжным провайдерам (Payme, Click).

3. Данные из 1С:Бухгалтерия

3.1. Для работы Сервиса Пользователь предоставляет API-ключ, через который агент BizPanel передаёт агрегированные финансовые метрики (выручка, задолженности, остатки денежных средств и т.д.).

3.2. Передаются только агрегированные цифры, не первичные документы. Персональные данные контрагентов, сотрудников и клиентов Пользователя не передаются.

3.3. Пользователь самостоятельно несёт ответственность за правомерность передачи данных Оператору.

4. Цели обработки

  • регистрация учётной записи и авторизация;
  • предоставление функционала Сервиса;
  • обработка платежей и выставление счетов;
  • направление транзакционных уведомлений (оплата, подписка, безопасность);
  • маркетинговые рассылки — исключительно при наличии явного согласия;
  • обеспечение безопасности Сервиса;
  • техническая поддержка;
  • исполнение требований законодательства Республики Узбекистан.

5. Сроки хранения

5.1. Данные учётной записи — на протяжении существования аккаунта плюс 3 года после удаления.

5.2. Данные метрик из 1С — согласно тарифу (от 7 дней до бессрочно).

5.3. Аудит-логи — 90 дней.

5.4. IP-адреса входа — не более 90 дней.

5.5. После удаления аккаунта данные удаляются в течение 30 дней, за исключением данных, хранение которых требуется по закону.

6. Третьи стороны

Render (Render Services, Inc., США) — хостинг backend и базы данных.
Передаваемые данные: все данные Сервиса. Сервер: США.
GitHub (GitHub, Inc., США) — хостинг frontend.
Передаваемые данные: статические файлы, без ПД.
Payme (ООО «PAYME», Узбекистан) — обработка платежей.
Передаваемые данные: сумма, идентификатор транзакции.
Click (ООО «Click», Узбекистан) — обработка платежей.
Передаваемые данные: сумма, идентификатор транзакции.
Telegram (Telegram FZ-LLC) — бот-уведомления.
Оператор не передаёт ПД в Telegram проактивно.
⚠ Данные хранятся на серверах в США (Render). Используя Сервис, Пользователь даёт согласие на трансграничную передачу данных.

7. Cookie-файлы

7.1. Сервис использует localStorage браузера для хранения JWT-токена авторизации и идентификатора пользователя.

7.2. Эти данные необходимы для работы Сервиса. Удаление приводит к выходу из аккаунта.

8. Права субъекта персональных данных

В соответствии с ЗРУ-547 Пользователь имеет право:

  • получить информацию об обработке своих ПД;
  • требовать уточнения, блокирования или удаления данных;
  • отозвать согласие на обработку ПД;
  • отказаться от маркетинговых рассылок;
  • обратиться в уполномоченный государственный орган по защите прав субъектов ПД.

Для реализации прав — запрос на: (email — заполнить). Срок ответа — 30 дней.

9. Безопасность

9.1. Меры защиты: HTTPS/TLS; хранение паролей в хешированном виде (bcrypt); JWT-токены с ограниченным сроком действия; rate limiting; API-ключи для агента 1С.

9.2. При обнаружении утечки Оператор уведомляет пострадавших Пользователей в течение 72 часов.

10. Маркетинговые коммуникации

10.1. Маркетинговые сообщения направляются исключительно при наличии явного согласия (чекбокс при регистрации, по умолчанию не отмечен).

10.2. Транзакционные сообщения направляются без дополнительного согласия.

11. Изменения политики

Актуальная редакция всегда доступна на данной странице. При существенных изменениях Пользователи уведомляются через Сервис или Telegram.
